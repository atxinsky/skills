## 💡 使用技巧

### 技巧1：提前准备好文章

**好的Markdown格式**：
```markdown
# 文章标题

开头段落...

## 小标题1

内容...

![配图](./images/图1.png)

## 小标题2

内容...
```

**注意**：
- 图片路径可以是相对路径或绝对路径
- 图片格式：JPG/PNG
- 图片大小：<10MB

---

### 技巧2：检查AI痕迹的关键词

**容易被检测的词**（建议提前避免）：
- "此外"、"总之"、"综上所述"
- "值得注意的是"、"需要指出的是"
- "首先...其次...最后..."
- "一方面...另一方面..."

**人话替换**：
- "此外" → "另外"、"还有"
- "总之" → "所以说"、"简单讲"
- "首先" → "第一个"、"先说"

---

### 技巧3：提升评分的方法

**钩子力（开头）**：
- 前3句要吸引人
- 用数据/反常识/提问开场
- <50字

**金句密度**：
- 每500字至少1个金句
- 金句标准：<30字，可以单独发朋友圈

**细节颗粒度**：
- 加真实案例（人名、公司名）
- 加数据对比
- 加具体场景描写

---

### 技巧4：封面设计建议

**选择模板**：
- 技术类文章 → `data` 或 `minimalist`
- 对比类文章 → `vs`
- 问答类文章 → `qa`
- 情感类文章 → `gradient`

**标题长度**：
- 理想长度：12-18字
- 最大长度：<30字（会自动换行）

## ❓ 常见问题

### Q1: 配置好了环境变量，但提示找不到？

**检查**：
```bash
# 在命令行执行
echo $WECHAT_APP_ID
# 或（Windows PowerShell）
echo $env:WECHAT_APP_ID
```

如果显示空，说明环境变量未生效，重新配置并重启终端。

---

### Q2: Canvas安装失败？

**Windows用户**：参考 `setup.md` 中的解决方案
- 使用预编译版本
- 或使用WSL环境

**macOS用户**：
```bash
brew install pkg-config cairo pango libpng jpeg giflib librsvg
npm install canvas
```

---

### Q3: 生成的封面图中文显示乱码？

**解决**：安装中文字体

**Windows**：系统自带，无需额外安装

**macOS/Linux**：
```bash
# 安装思源黑体
sudo apt-get install fonts-noto-cjk  # Ubuntu
brew install font-source-han-sans    # macOS
```

修改 `generate-cover.js` 中的字体设置：
```javascript
ctx.font = 'bold 48px "Source Han Sans", "Microsoft YaHei", sans-serif';
```

---

### Q4: 文章评分总是很低怎么办？

**常见原因**：
1. AI痕迹太重（先用humanizer-zh处理）
2. 缺少金句（每500字至少1个）
3. 开头不吸引人（前3句要有钩子）
4. 缺少案例/数据

**建议**：
- 先看评分报告的具体问题
- 针对性修改
- 重新评分

---

### Q5: 草稿创建失败？

**可能原因**：
1. access_token过期 → 重新运行会自动刷新
2. 图片太大 → 压缩到<10MB
3. 草稿箱已满 → 删除旧草稿（上限100个）
4. AppID/Secret配置错误 → 检查环境变量
