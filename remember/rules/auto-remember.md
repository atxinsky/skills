# 自动记忆规则 (MANDATORY)

## 何时自动保存记忆

在以下情况下，**必须**自动执行 `/remember` skill 保存本次会话记忆，无需用户手动触发：

1. **完成重要任务后** — 修改了代码、做了架构决策、解决了 bug
2. **会话即将结束时** — 用户说"好了"、"就这样"、"谢谢"、"commit"等结束语
3. **发现重要教训时** — 踩坑、发现关键规律、API 行为与预期不同
4. **产生待办事项时** — 有未完成的工作需要下次会话继续

## 何时不保存

- 简单问答（"这个函数是干什么的？"）
- 闲聊、讨论想法但未产生决策
- 只读操作（查看代码、搜索文件）

## 执行方式

直接调用 `/remember` skill，不需要问用户"要不要保存记忆"。静默保存即可。
