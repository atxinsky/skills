# Humanizer-ZH - 中文AI去痕专家

## 💡 Skill简介

这是一个专门检测和去除中文AI写作痕迹的工具，让你的文章更像人写的。

**核心能力**：
- 识别24种常见AI写作模式
- 自动替换AI高频词汇
- 重构过于工整的句式
- 注入个人风格和情感

**效果对比**：
- AI痕迹评分：从80% → 降至20%以下
- 阅读体验：从"像说明书"→"像朋友聊天"

---

## 🔍 AI写作的24种痕迹

### 1. 高频套话词汇（10个）

| AI词汇 | 人话替换 |
|--------|----------|
| 此外 | 另外 / 还有 / 再说 |
| 总之 | 说白了 / 简单讲 |
| 综上所述 | 总的来说 / 所以呢 |
| 至关重要 | 很重要 / 关键 |
| 不可或缺 | 少不了 / 必须有 |
| 值得注意的是 | 注意 / 重点来了 |
| 需要指出的是 | 要说的是 / 强调一下 |
| 显而易见 | 很明显 / 大家都知道 |
| 毋庸置疑 | 肯定 / 没跑了 |
| 不言而喻 | 不用说 / 大家懂的 |

### 2. 工整的三段式结构（3种）

❌ **AI写法**：
```
首先，我们需要...
其次，我们应该...
最后，我们可以...
```

✅ **人话改写**：
```
第一步，...
然后呢，...
做完这两步，你就会发现...
```

### 3. 过度使用被动语态（2种）

❌ **AI写法**：
- "被认为是..."
- "被广泛应用于..."

✅ **人话改写**：
- "大家觉得..."
- "到处都在用..."

### 4. 缺乏个人观点（3种）

❌ **AI写法**：
- 客观陈述事实
- 没有情感色彩
- 没有"我"的视角

✅ **人话改写**：
- 加入"我觉得..."
- 加入"真的很..."（情感词）
- 加入个人经历/案例

### 5. 段落结构过于工整（2种）

❌ **AI写法**：
- 每段长度相似
- 每段都有总分总结构

✅ **人话改写**：
- 长短段落穿插
- 适当使用单句成段（强调效果）

### 6. 缺乏口语化表达（4种）

❌ **AI写法**：
- "这一点很重要"
- "我们需要注意"
- "建议采取措施"
- "可以得出结论"

✅ **人话改写**：
- "这事儿挺关键的"
- "别踩这个坑"
- "试试这么做"
- "所以说呢"

## 📝 使用方法

### 基础用法
```bash
/humanizer-zh [文章路径或文本]
```

### 输入示例
```markdown
在当今数字化时代，人工智能技术已经深入到我们生活的方方面面。首先，AI在医疗领域的应用值得关注。其次，教育行业也受益于AI技术的发展。最后，我们需要认识到AI技术的重要性。总之，AI将改变我们的未来。
```

### 输出示例
```markdown
## AI痕迹检测报告

**原文AI痕迹评分**：85% 🔴 （高风险）

### 检测到的AI模式

1. ❌ **套话词汇**（4处）
   - "在当今数字化时代" → 建议删除或改为"现在"
   - "值得关注" → 改为"很有意思"
   - "总之" → 改为"所以说"
   - "重要性" → 改为"有多重要"

2. ❌ **工整结构**（首先/其次/最后）
   - 建议打乱顺序，用"1、2、3"或"第一件事、还有、另外"

3. ❌ **缺乏个人观点**
   - 全文都是客观陈述，缺少"我觉得""我发现"

4. ❌ **过于正式**
   - 建议加入口语化表达
```

## 🎨 去痕策略

### 策略1：词汇替换表

创建`~/.claude/skills/humanizer-zh/ai-words.json`：

```json
{
  "formal_to_casual": {
    "此外": ["另外", "还有", "再说"],
    "总之": ["说白了", "简单讲", "所以说"],
    "至关重要": ["很重要", "关键", "必须"],
    "值得注意": ["注意", "重点来了", "划重点"],
    "显而易见": ["很明显", "大家都知道", "不用说"]
  },
  "remove_completely": [
    "在当今",
    "随着...的发展",
    "众所周知",
    "毋庸置疑",
    "不言而喻"
  ]
}
```

### 策略2：句式重组

**原则**：打破工整，增加变化

❌ 工整句式：
```
第一，...
第二，...
第三，...
```

✅ 改写：
```
先说第一个，...

然后呢，...（用问句打断节奏）

最后一点也很关键：...
```

### 策略3：注入个人风格

**方法**：
1. 加入"我"的视角
2. 加入真实经历/数据
3. 加入情感词（真的、挺、超、特别）
4. 加入口头禅（"说实话""老实讲""你懂的"）

**示例**：

❌ AI写法：
```
ChatGPT在写作领域的应用非常广泛。
```

✅ 人话改写：
```
ChatGPT这玩意儿，我真的天天都在用。写文案、改文章、头脑风暴，基本离不开了。
```

### 策略4：增加"不完美"

**真实的人话特征**：
- 偶尔有重复（"真的真的很好用"）
- 会用省略号（"嗯...我觉得..."）
- 会自我纠正（"不对，应该说..."）
- 会有停顿词（"就是那个...""怎么说呢"）

## 🎓 去痕原则

### 核心思维
**AI = 完美、工整、客观**
**人话 = 不完美、随性、主观**

### 检查清单

写完文章后，问自己：

- [ ] 有没有用"首先/其次/最后"？
- [ ] 有没有用"此外/总之/综上所述"？
- [ ] 有没有个人经历或观点？
- [ ] 读起来像朋友聊天吗？
- [ ] 有没有情感词（真的、超、挺）？
- [ ] 段落长度有变化吗？
- [ ] 有没有反问句？
- [ ] 有没有单句成段？

全部YES → AI痕迹<20%

## 💡 实战案例

### 案例1：知乎回答去痕

**原文（AI生成）**：
```
要提高写作能力，需要从以下几个方面入手：

首先，大量阅读是基础。通过阅读优秀作品，可以学习到各种写作技巧和表达方式。

其次，坚持练习很重要。每天写作500字，持之以恒，写作水平就会逐步提升。

最后，要勇于修改。好文章都是改出来的，不要害怕推翻重来。

总之，写作是一个需要长期积累的过程。
```

**AI痕迹评分：88%** 🔴

**修改后（去痕版本）**：
```
想写好文章？我的经验就三个字：读、写、改。

读什么？读你想写的那个领域的好文章。比如我想写公众号爆款文，就天天研究咪蒙、刘润这些大号的套路。

写多少？我刚开始每天逼自己写500字，什么都行，日记也好，吐槽也行。写了三个月，明显感觉下笔更顺了。

改几遍？说实话，我现在一篇文章至少改5遍。第一遍写完，隔天再看，会发现一堆问题。

别指望一蹴而就，写作这事儿，就是个熟练工种。
```

**AI痕迹评分：15%** 🟢

## 📌 注意事项

1. **不要过度去痕**：适当的书面语是必要的
2. **保持专业性**：技术文章不能太口语化
3. **因文制宜**：正式文档不需要去痕
4. **人工复核**：工具只是辅助，最后要人工检查
