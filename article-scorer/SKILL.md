# Article Scorer - 文章质量评分系统

## 💡 Skill简介

这是一个多维度文章质量评估系统，从6个角度给文章打分，帮助你在发布前找出问题。

**核心能力**：
- 115分制全面评分（含加分项）
- 定位具体问题位置
- 给出可操作的改进建议
- 对标爆款文章标准

**适用场景**：
- 公众号文章发布前审查
- 知乎回答质量把关
- 小红书文案优化

---

## 📊 评分标准（115分制）

### 1. 钩子力（20分）- 开头3秒能否抓住人

**评分细则**：

| 分数 | 标准 | 示例 |
|------|------|------|
| 18-20分 | 前3句就让人想继续读 | "你有没有发现，点赞10万+的文章，开头都用了这3个套路。" |
| 15-17分 | 开头有亮点，但不够强 | "今天分享3个写作技巧。" |
| 10-14分 | 平淡开局，缺乏吸引力 | "写作是一件很重要的事情。" |
| 0-9分 | 废话开局，让人想退出 | "在当今数字化时代..." |

**检查要点**：
- [ ] 是否有冲突/反常识/痛点
- [ ] 是否用了数据/案例开场
- [ ] 是否有悬念/提问
- [ ] 前3句字数<50字

---

### 2. 情绪曲线（20分）- 是否有起伏

**评分细则**：

| 分数 | 标准 |
|------|------|
| 18-20分 | 有高潮、有低谷、有转折 |
| 15-17分 | 有一定起伏，但不够明显 |
| 10-14分 | 平铺直叙，缺乏变化 |
| 0-9分 | 一马平川，读着想睡 |

**检查要点**：
- [ ] 有没有让人紧张的部分
- [ ] 有没有让人松一口气的部分
- [ ] 有没有反转
- [ ] 有没有情绪词（兴奋、失望、惊讶）

**情绪曲线示意图**：
```
高潮（冲突、反转）
  ↗      ↘
开局      结尾
  ↘      ↗
低谷（铺垫、蓄力）
```

---

### 3. 金句密度（20分）- 有没有让人想划线的句子

**评分细则**：

| 分数 | 标准 |
|------|------|
| 18-20分 | 每500字至少1个金句 |
| 15-17分 | 全文有2-3个金句 |
| 10-14分 | 只有1个金句 |
| 0-9分 | 没有金句 |

**金句标准**：
- 可以单独拎出来发朋友圈
- 简短有力（<30字）
- 有观点/有态度
- 让人点头认同或震惊

**示例**：
✅ "最快的速度，不是跑得快，而是不用跑。"
✅ "好的选题，是让读者看到标题就忍不住点开。"
❌ "我们要认识到写作的重要性。"（太泛）

---

### 4. 细节颗粒度（20分）- 是否有具体案例/数据

**评分细则**：

| 分数 | 标准 |
|------|------|
| 18-20分 | 每个观点都有案例/数据支撑 |
| 15-17分 | 大部分观点有支撑 |
| 10-14分 | 只有少量案例 |
| 0-9分 | 全是空洞观点 |

**检查要点**：
- [ ] 有没有真实案例（人名、公司名、具体场景）
- [ ] 有没有数据（涨幅%、对比数字）
- [ ] 有没有细节描写（对话、动作）
- [ ] 有没有时间地点

**对比**：
❌ "这个方法很有用。"（太虚）
✅ "我用这个方法，公众号阅读量从500涨到5000，涨了10倍。"（有数据）

---

### 5. 共鸣点（20分）- 读者能否产生共鸣

**评分细则**：

| 分数 | 标准 |
|------|------|
| 18-20分 | 多处让读者感同身受 |
| 15-17分 | 有共鸣点，但不够多 |
| 10-14分 | 只有少量共鸣 |
| 0-9分 | 读者无感 |

**共鸣来源**：
1. **痛点共鸣** - "你是不是也遇到过..."
2. **情感共鸣** - "我当时真的很崩溃..."
3. **经历共鸣** - "刚毕业那会儿..."
4. **观点共鸣** - "我一直觉得..."

**检查方法**：
- 读者会不会说"对对对，就是这样"
- 会不会觉得"这就是在说我"

---

### 6. 结尾余韵（15分）- 结尾是否有回味

**评分细则**：

| 分数 | 标准 |
|------|------|
| 13-15分 | 强收尾，让人想二刷 |
| 10-12分 | 收尾不错，但不惊艳 |
| 5-9分 | 平淡收尾 |
| 0-4分 | 虎头蛇尾 |

**好结尾的3种类型**：
1. **升华型** - 从具体到抽象，提炼主题
2. **行动型** - 给出明确的下一步建议
3. **回应型** - 呼应开头，形成闭环

**示例**：
✅ 升华型："所以说，写作的本质，不是炫技，而是真诚。"
✅ 行动型："今天就去试试，写出你的第一篇人话文章。"
✅ 回应型：开头问"为什么有人写文章10万+"，结尾答"因为他们都做对了这3件事"

---

## 💯 加分项（+15分）

### 1. 标题党指数（+5分）
- 标题是否吸引人
- 是否用了数字/疑问/悬念

### 2. 排版美观度（+5分）
- 是否有小标题
- 是否有图片/表格
- 段落长度是否适中

### 3. 互动设计（+5分）
- 是否有提问
- 是否引导评论/转发
- 是否有福利/彩蛋

## 📝 使用方法

### 基础用法
```bash
/article-scorer [文章路径]
```

### 输入示例
```markdown
~/我的文章/如何写好公众号.md
```

### 输出示例
```markdown
## 📊 文章质量评分报告

**文章标题**：如何用AI工具10分钟做出公众号封面图

**总分**：88/115分 🟢 优秀

---

### 📈 各维度得分

**1. 钩子力：18/20分** ⭐⭐⭐⭐⭐
- ✅ 开头用痛点+数字吸引人
- ✅ 前3句简洁有力
- ⚠️ 可以加入一个反问句增强互动

**2. 情绪曲线：16/20分** ⭐⭐⭐⭐
- ✅ 有起伏，体现在"之前很难→现在很简单"的转变
- ⚠️ 缺少高潮部分，建议加入一个惊喜案例
- ⚠️ 情绪词偏少，可以加入"惊呆了""太爽了"

**3. 金句密度：15/20分** ⭐⭐⭐⭐
- ✅ 全文有3个金句
  - "最快的封面图，不是做得快，而是不用做"（第2段）
  - "好工具+好模板=10分钟搞定"（第5段）
  - "省下时间，去做更重要的事"（结尾）
- ⚠️ 金句分布不均，建议前半部分再加1个

**4. 细节颗粒度：20/20分** ⭐⭐⭐⭐⭐
- ✅ 有真实数据（对比3款工具的实际效果）
- ✅ 有步骤截图
- ✅ 有Before/After对比
- ✅ 有具体操作细节（"先选模板→输入标题→一键生成"）

**5. 共鸣点：14/20分** ⭐⭐⭐⭐
- ✅ 痛点共鸣："每次做封面图都要1小时"（第1段）
- ✅ 经历共鸣："我之前也是用PS，累死累活"（第3段）
- ⚠️ 可以加入更多读者的真实反馈或评论

**6. 结尾余韵：12/15分** ⭐⭐⭐⭐
- ✅ 有行动号召："今天就试试"
- ⚠️ 缺少升华，建议加一句总结性金句

**加分项：+13分**
- 标题党指数：+5分（用了数字"10分钟"）
- 排版美观度：+5分（有小标题、有对比表格）
- 互动设计：+3分（有提问，但缺少福利引导）

---

### 🎯 总体评价

**优势**：
1. 开头抓眼球，痛点明确
2. 细节丰富，有真实数据支撑
3. 排版清晰，阅读体验好

**待优化**：
1. 情绪曲线不够明显，建议加入一个"哇塞"时刻
2. 金句偏少，建议再增加1-2个
3. 共鸣点可以更丰富，加入更多读者案例

---

### 💡 改进建议（Top 3）

**建议1：增加情绪高潮（优先级：高）**
- 位置：第4段工具对比后
- 方法：加入一个惊喜案例
- 示例："我有个朋友，用这个方法做了100张封面图，只花了30分钟。你敢信？"

**建议2：丰富金句（优先级：中）**
- 位置：第3段结尾
- 方法：提炼观点成金句
- 示例："工具只是工具，模板才是灵魂。"

**建议3：强化结尾（优先级：低）**
- 位置：最后一段
- 方法：加入升华句
- 示例："做封面图这件事，本质上是在设计注意力的入口。入口做好了，内容才有机会被看到。"

---

### 📌 对标爆款标准

| 金句密度 | 15 | 18+ | ⚠️ 还差3分 |

**结论**：
- 当前总分88分，爆款标准95+
- 重点提升：情绪曲线、金句密度、共鸣点

**是否继续优化？**
- [ ] 是，根据建议修改后再评分
```

## 🔧 高级功能

### 1. 对比模式
对比两篇文章，看哪篇更好：

```bash
/article-scorer --compare 文章A.md 文章B.md
```

输出：
```
文章A：88分（优势：钩子强、细节足）
文章B：76分（优势：共鸣好、结尾佳）

建议：取A的开头+B的结尾，重新组合
```

### 2. 批量评分
评估文件夹下所有文章：

```bash
/article-scorer --batch ~/草稿文件夹/
```

输出：按分数排序的文章列表

### 3. 爆款分析模式
分析爆款文章的得分：

```bash
/article-scorer --analyze-hit ~/爆款案例.md
```

输出：
```
钩子力：20/20 - 用了"惊人发现"开局
情绪曲线：19/20 - 三次反转，节奏完美
金句密度：18/20 - 每300字1个金句
...

学习要点：
1. 开头用反常识吸引
2. 中间用案例堆情绪
3. 结尾用金句升华
```

## 📌 注意事项

1. **评分仅供参考**：分数不是唯一标准，读者反馈才是
2. **因文制宜**：技术文章和情感文章评分侧重不同
3. **持续迭代**：根据实际阅读数据调整评分权重
4. **不要为了分数而写**：真诚最重要

---

## 🚀 快速开始

**Step 1**: 写完文章（Markdown格式）

**Step 2**: 运行评分
```bash
/article-scorer 文章.md
```

**Step 3**: 查看报告，根据建议修改

**Step 4**: 再次评分，确保85分以上
